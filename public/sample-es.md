# Guión de Ejemplo para el Teleprompter

Bienvenido a **Apuntador**, tu aplicación de teleprompter móvil.

## Primeros Pasos

Este es un guión de ejemplo para ayudarte a probar la funcionalidad del teleprompter. El texto se desplazará automáticamente cuando presiones el botón de reproducir.

### Características Principales

- **Desplazamiento automático** con velocidad ajustable
- **Banda de resaltado** para enfocar las líneas actuales
- **Controles táctiles** optimizados para móviles
- **Modos espejo** para configuraciones profesionales
- **Soporte Markdown** para formato enriquecido

## Usando el Teleprompter

1. **Reproducir/Pausar**: Toca el botón de reproducir o presiona la barra espaciadora
2. **Control de Velocidad**: Usa los botones de velocidad o las teclas `[` y `]`
3. **Navegación por Líneas**: Desliza arriba/abajo o usa las flechas del teclado
4. **Tamaño de Fuente**: Usa los botones de fuente o las teclas `+` y `-`
5. **Espejo**: Activa el reflejo horizontal o vertical

### Gestos Táctiles

- **Toque simple**: Mostrar/ocultar barra de herramientas
- **Deslizar arriba/abajo**: Navegar por líneas
- **Mantener presionado**: Acceso rápido a controles

### Atajos de Teclado

- `Espacio`: Reproducir/Pausar
- `↑/↓`: Línea anterior/siguiente
- `Inicio/Fin`: Ir al inicio/final
- `←/→`: Disminuir/Aumentar velocidad
- `+/-`: Aumentar/Disminuir tamaño de fuente
- `H/V`: Alternar espejo horizontal/vertical
- `E`: Abrir editor
- `S`: Abrir configuración

## Características Avanzadas

### Banda de Resaltado

La **banda de resaltado** te ayuda a enfocar la posición de lectura actual. Puedes:

- Ajustar su altura (1 o 2 líneas)
- Mover su posición vertical
- Controlar la intensidad del oscurecimiento

### Modos Espejo

Perfectos para configuraciones profesionales de teleprompter:

- **Horizontal**: Refleja el texto de izquierda a derecha
- **Vertical**: Refleja el texto de arriba hacia abajo
- **Ambos**: Rotación completa de 180°

### Importar Archivos

Importa tus propios guiones:

- Arrastra y suelta archivos `.md` o `.txt`
- Usa el selector de archivos en configuración
- Todo el contenido se almacena localmente

## Personalización

Personaliza tu experiencia con el teleprompter:

- **Familia y tamaño de fuente**
- **Colores** (texto y fondo)
- **Rango de velocidad** de desplazamiento
- **Altura de línea** para mejor legibilidad
- **Apariencia de la banda** de resaltado
