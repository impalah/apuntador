Bluetooth HID / Keyboard / Gamepad Tester

Use this tester to see what events your device sends (keys, gamepad and/or HID). On Android, Keyboard and Gamepad work; WebHID only on desktop (Chrome/Edge).

1) Keyboard (KeyboardEvent)

Focus the area below and press buttons. Check the box to block default actions (scroll, etc.).

Click here to focus and test your device. You can also type in this area.
Android tips: Settings → Language & Input → Physical Keyboard → Enable if available. Some special keys might not map.

3) WebHID (desktop only)

This allows listening to raw HID reports (e.g., "consumer control" keys not mapped to keyboard or gamepad). Requires Chrome/Edge on desktop.

Note: On Android, WebHID is not available. On desktop, it may ask for permission each time.
