# Sample Teleprompter Script

Welcome to **Apuntador**, your mobile-first teleprompter application.

## Getting Started

This is a sample script to help you test the teleprompter functionality. The text will auto-scroll when you press the play button.

### Key Features

- **Auto-scrolling** with adjustable speed
- **Highlight band** to focus on current lines
- **Mobile-friendly** touch controls
- **Mirror modes** for professional setups
- **Markdown support** for rich formatting

## Using the Teleprompter

1. **Play/Pause**: Tap the play button or press spacebar
2. **Speed Control**: Use the speed buttons or `[` and `]` keys
3. **Line Navigation**: Swipe up/down or use arrow keys
4. **Font Size**: Use the font buttons or `+` and `-` keys
5. **Mirror**: Toggle horizontal or vertical mirroring

### Touch Gestures

- **Single tap**: Show/hide toolbar
- **Swipe up/down**: Navigate by lines
- **Press and hold**: Quick access to controls

### Keyboard Shortcuts

- `Space`: Play/Pause
- `↑/↓`: Previous/Next line
- `Home/End`: Go to start/end
- `←/→`: Decrease/Increase speed
- `+/-`: Increase/Decrease font size
- `H/V`: Toggle horizontal/vertical mirror
- `E`: Open editor
- `S`: Open settings

## Advanced Features

### Highlight Band

The **highlight band** helps you focus on the current reading position. You can:

- Adjust its height (1 or 2 lines)
- Move its vertical position
- Control the dimming intensity

### Mirror Modes

Perfect for professional teleprompter setups:

- **Horizontal**: Mirror text left-to-right
- **Vertical**: Mirror text top-to-bottom
- **Both**: Complete 180° rotation

### File Import

Import your own scripts:

- Drag and drop `.md` or `.txt` files
- Use the file picker in settings
- All content is stored locally

## Customization

Personalize your teleprompter experience:

- **Font family and size**
- **Colors** (text and background)
- **Scroll speed** range
- **Line height** for better readability
- **Highlight band** appearance
