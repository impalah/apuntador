# Getting Started

Welcome to Apuntador! This guide will help you get up and running quickly with your new teleprompter application.

## What is Apuntador?

Apuntador is a professional-grade teleprompter designed for content creators, presenters, and public speakers. Built with modern web technologies, it provides a smooth, customizable reading experience that works on any device.

## Key Features at a Glance

- **Auto-scrolling** with precise speed control
- **Mirror modes** for professional setups
- **Highlight band** to maintain reading focus
- **Touch gestures** for mobile control
- **Keyboard shortcuts** for desktop efficiency
- **File import** for existing scripts
- **Complete privacy** - no data leaves your device

## Quick Start Tutorial

### 1. Load Your First Script

There are three ways to get content into Apuntador:

**Option A: Use the Sample Content**

- The app loads with sample content automatically
- Perfect for testing features and getting familiar

**Option B: Import a File**

1. Click the **Import** button (📁 icon)
2. Select a `.md` or `.txt` file from your device
3. Content loads automatically

**Option C: Use the Editor**

1. Click the **Editor** button (✏️ icon)
2. Type or paste your script
3. Use markdown formatting for headers, emphasis, etc.
4. Click **Save** when finished

### 2. Basic Controls

**Play/Pause**

- Click the **Play** button ([PLAY]) to start auto-scrolling
- Click **Pause** ([PAUSE]) to stop
- Use **Spacebar** on desktop for quick toggle

**Speed Control**

- Use **+/-** buttons to adjust scroll speed
- Speed range: 10-200 pixels per second
- Find your comfortable reading pace

**Navigation**

- **Rewind/Forward** buttons move by lines
- **Home/End** buttons jump to start/finish
- Use arrow keys on desktop

### 3. Customize Your Experience

**Font and Display**

1. Open **Settings** (⚙️ icon)
2. Adjust **Font Size** (16-200px)
3. Change **Font Family** if desired
4. Set **Colors** for text and background

**Highlight Band**

1. Enable the reading focus band
2. Adjust **Height** (1 or 2 lines)
3. Set **Position** (where on screen)
4. Control **Dimming** intensity

### 4. Professional Setup

**Mirror Modes** (for beam-splitter glass):

- **Horizontal**: Most common for teleprompters
- **Vertical**: For specific camera angles
- **Both**: Complete 180° rotation

**Fullscreen Mode**

- Click fullscreen button for distraction-free reading
- Press **Escape** to exit
- Perfect for presentations

## Mobile Usage Tips

### Touch Controls

- **Single tap**: Show/hide toolbar
- **Swipe up/down**: Navigate by line
- **Press and hold**: Quick access to speed controls

### Mobile Optimization

- Toolbar automatically minimizes on small screens
- Touch targets are sized for easy finger access
- Responsive design adapts to any screen size

### Battery Saving

- Pause when not actively reading
- Reduce brightness for longer sessions
- Close other apps to free up memory

## Best Practices

### Script Preparation

- Use clear, simple language
- Break long sentences into shorter ones
- Add pauses with blank lines
- Use headers to organize sections

### Reading Technique

- Position screen at eye level
- Maintain comfortable distance (arm's length)
- Set speed slightly slower than natural speech
- Practice with sample content first

### Professional Tips

- Test setup before important recordings
- Have backup scripts ready
- Use consistent formatting
- Practice mirror mode if needed

### Getting Help

If you encounter issues:

1. Review the troubleshooting section below
2. Check browser compatibility requirements
3. Report bugs on [GitHub Issues](https://github.com/yourusername/apuntador/issues)

### Common Troubleshooting

**Scrolling is too fast/slow**

- Adjust speed with +/- buttons
- Find your natural reading rhythm
- Speed can be changed during playback

**Text is too small/large**

- Use font size controls in settings
- Test readability at your working distance
- Consider screen size and resolution

**Mirror mode looks wrong**

- Check if you need horizontal, vertical, or both
- Test with camera setup before recording
- Adjust based on your equipment

**Touch controls not working**

- Ensure screen is clean
- Try single tap to show toolbar
- Check if browser supports touch events
